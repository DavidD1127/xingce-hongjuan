## 验证结果

- Python 标准库回归测试 **12 项全部通过**，包括空题库保护、重建保留进度、故意触发写入失败后的回滚、导入往返与回滚、材料边界、HTTP 路由、越界路径、无图 APK 清理。
- 初版 10 项测试放回未修复基线，**6 项失败**，证明主要缺陷可复现。
- Python 语法、JavaScript 语法、`git diff --check` 通过；CI 新增相同回归测试，Pillow 仅用于 APK 资源测试。
- Playwright 浏览器实测：抽题、选择、揭晓、保存笔记、自评连续点击；记录仅写入一次，笔记保存后四档自评仍在；HTML 过滤保留本地图和加粗。
- Android 模拟器使用独立包 `com.huasufang.hongjuan.review`，测试库为 12 道示例题：抽题、判分、笔记、收藏、错误导入拒绝、进度导入导出、列表复习间隔均通过。
- 覆盖安装测试：更换题库版本后笔记、收藏、作答记录保留，旧库备份存在。
- 迁移故障测试：故意移除旧库的一张表，确认事务回滚并恢复原库，笔记和作答记录保留，数据库版本标记未前移。
- 完整库只读检查：SQLite `quick_check=ok`，27,473 题。原学习记录未改动。
- Windows 使用 JDK 17、SDK 34 编译资源、Java 与 DEX，生成完整 APK **约 155.7 MiB**；最终 DEX 更新后重新打包签名，v1/v2/v3 签名验证通过，签名身份与原包相同。
- 最终 APK ZIP 完整性通过；包内 27,473 题，四张学习记录表均为空，题库版本标记存在；正式包无 debuggable 标记。
