## 这版改了什么

- 选项里的分数、根号等公式图不再空白。修了两处：打包改写图片路径时多拼了一个引号；设备端一直沿用第一版题库，新包换名后图片全部 404
- 换新包时做题记录自动迁移，覆盖安装不用卸载重装
- 今日页新增「进度保险」：做题记录可导出，换机后粘贴导入
- 资料分析的长材料增加「展开」，不再被 38vh 限高卡住
- 图片缺失时显示「图缺失」占位，不再是空白一片，便于区分数据缺图与渲染问题
- 材料题的题干与材料对应关系做了修正，减少无关材料出现在普通题上的情况

## 安装

下载到的文件是 zip 包，解压后得到 `行测红卷.apk`，再安装（GitHub 的附件白名单不含 apk，因此套了一层压缩）。

APK 未上架任何应用商店，安装时系统会有几次拦截，属正常现象：

1. 下载后若浏览器提示「无法打开文件」，将后缀改为 `.zip` 再改回 `.apk`，或在文件管理中选择「用其他应用打开」
2. 允许「安装未知来源应用」
3. 一加 / OPPO 机型需关闭「纯净模式」

覆盖安装不会丢失做题记录。跨设备迁移时，先在旧设备「今日 → 进度保险」导出，新设备安装后在同一位置粘贴导入。

## 说明

- 题库与配图全部打包在安装包内，**无需联网**
- 首次启动需将题库解压至应用目录，后续启动较快
- 做题记录仅保存在本机，不上传任何服务器

## 校验

证书 SHA-256 指纹：

```
60A4:8974:2331:1074:A7F7:8924:AEBA:AF22:6F27:FCC9:1A60:BA39:FCF3:D2D6:4E77:7E80
```

```
apksigner verify --print-certs 行测红卷.apk
```

指纹一致即表示由同一签名构建。
