- 选项里的分数、根号等公式图不再空白（修了打包改写路径多拼引号、以及旧题库没被替换两个问题）

- 图片缺失时显示「图缺失」占位，不再是空白一片

## 安装

APK 没有上架任何应用商店，手机装的时候会拦几次，属于正常现象：

1. 下载后如果浏览器提示「无法打开文件」，把后缀改成 `.zip` 再改回 `.apk`，
   或者在文件管理里直接选「用其他应用打开」
2. 允许「安装未知来源应用」
3. 一加/OPPO 机型关掉「纯净模式」

覆盖安装不会丢做题记录。换手机的话，先在旧机的「今日 → 进度保险」里导出，
新机装好后在同一处粘贴导入。

## 说明

- 题库、配图全部打包在安装包里，**不联网也能用**
- 首次启动会把题库解到应用目录，等几秒；之后秒开
- 做题记录只存在本机，不上传任何地方

## 校验

包内证书 SHA-256 指纹：

```
60A4:8974:2331:1074:A7F7:8924:AEBA:AF22:6F27:FCC9:1A60:BA39:FCF3:D2D6:4E77:7E80
```

```
apksigner verify --print-certs 行测红卷.apk
```

对得上就是同一个签名出的包。
